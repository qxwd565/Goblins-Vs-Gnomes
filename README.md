# Goblins Vs Gnomes: HSdeck API

한국 날짜(Asia/Seoul) 기준 고블린 대 노움 카드 API입니다. 143개 ID(수집 가능 123장, 생성 토큰·선택지·예비 부품 20개)를 유지합니다.

- `data/<ID>.json`: 최상위 키가 오름차순 날짜입니다. 최초 날짜에는 당시 확인 가능한 스펙, 이후 날짜에는 변경 필드만 기록합니다. 삭제는 `__remove`로 구분합니다.
- `metadata/<ID>.json`: 기존 원본 JSON 전체, 현재 카탈로그, 원시 자료, 출처 커밋, 신뢰도와 미확정 관측을 보존합니다.
- `cards.json`: 현재 카드 ID/DBF ID 및 표시용 카드 목록입니다. 카드별 한국 날짜 이력은 `data/`에서 직접 읽습니다.
- `release-policy.json`, `manifest.json`, `art/`, `golden/`: 기존 자료, ID와 경로를 유지합니다.

최초 한국 일반 덱 실사용일은 **2014-12-10**입니다. 클라이언트 사전 추가나 투기장 사전 체험과 구분합니다. 기존 55개 이벤트를 보존합니다. 야수/기계 복합 종족 4장(GVG_030/034/048/076)의 적용일은 출처에 따라 2022-11-30에서 **2023-02-15**로 바로잡습니다. 기존 이벤트 8개에는 검증된 키워드 능력 변경을 함께 기록합니다. 일반 효과 전체나 모든 엔진 플래그를 능력 목록으로 모델링한 것은 아닙니다.

**역사 검증은 부분 완료입니다.** 최초 한국어 표시 문구 99개의 차이, 함포 4.1 문구의 정확한 적용일, V-07-TR-0N 희귀도 변경 시점 등은 미확정입니다. 원본의 `rarity: null`은 해당 카드에서 미확정 값이지 역사적 희귀도 부재가 확인됐다는 뜻이 아닙니다. 모든 전체 최초 스펙은 `partially-verified` 상태입니다.

상세 형식과 호환 손실, 출처, 한계 및 전체 검사 명령은 [docs/date-schema.md](docs/date-schema.md)를 확인하세요. 이전 밸런스 감사는 [BALANCE-AUDIT.md](BALANCE-AUDIT.md), 재확인 출처는 `tools/gvg-date-recheck.json`에 있습니다.

빌드: `python3 tools/migrate-date-schema.py` 다음 `python3 tools/build-api.py`.

기본 검사: `python3 tools/test-gvg-history.py`, `python3 tools/test-date-schema.py`, `python3 tools/test-gvg-mechanics.py`, `python3 tools/test-legacy-compatibility.py`.

생성 번들을 직접 수정하지 말고 개별 날짜 원본을 고친 뒤 재생성합니다. 현재 원시 `nativeTags`를 과거 시점 스펙으로 해석하지 마세요. 원시 자료의 실제 개행은 보존하며 표시 문구만 `<br></br>` 형식을 씁니다. 플러그인 변경이나 실사이트 가져오기는 이 저장소 작업에 포함하지 않습니다.

## 2026-11-13 고놈 최초 실사용일 전체 재검증

[143개 ID별 모드 구분 및 토큰 부모 감사 기록](tools/gvg-first-use-verification-20261113.json)을 추가했습니다. 한국에서는 고놈 카드 전종이 **2014-12-05 투기장에 먼저 투입**됐고(블리자드 공식 공지 및 인벤 당시 보도), 카드팩 구매·제작과 일반 덱 사용은 서버 문제로 하루 연기된 **2014-12-10**부터 가능합니다. 따라서 현재 일반 덱용 `releasedAt=2014-12-10`은 그대로 유지하고, 실제 투기장 선공개 실사용 가능일을 143개 카드 모두의 별도 기록으로 남겼습니다. 이는 개별 카드가 12월 5일 실제로 뽑혔다는 로그는 아닙니다.

수집 가능 123종과 토큰/선택지/예비 부품 20종의 ID를 전부 비교하고, 원본 메타데이터의 `relatedIds` DBF 참조로 비수집 20개를 부모 15종과 대조했습니다. 총 7개 예비 부품·6개 선택지·7개 생성/변신 카드는 모두 부모가 확인됐습니다. `python3 tools/test-gvg-first-use.py`를 CI에 추가했으며 **이번 감사에서는 카드의 능력치·밸런스·날짜 키나 원본 증거를 변경하지 않았습니다**. 기존 한국어 최초 문구 99건의 미완성 검증은 계속 별도 범위입니다.


## API 경량화·편집 지침 (2026-11-14)

- **게시할 카드 데이터는 `cards.json`(현재 카드 목록)과 `data/<카드ID>.json`(날짜별 변경 기록)**입니다. 나머지 `render*.json`, `history*.json`, `cards-date.json`은 테스트 과정의 임시 생성물일 뿐, GitHub에 커밋하거나 배포하지 않습니다.
- 카드 원화 `art/`, 황금 원화·애니메이션 `golden/`, 프레임 `frame/`은 실제 사용 여부를 확인한 뒤 그대로 유지합니다. 바이너리 파일, 재질, 셰이더, 링크를 임의 수정하지 않습니다.
- 최초 날짜는 **한국 시간 실제 대전 가능일**입니다. 모험모드는 지구 개방, 이벤트는 행사 개시를 적용하며 클라이언트 사전 탑재일을 쓰지 않습니다. 토큰과 선택지도 부모 효과 및 생성 가능일을 검사합니다.
- `data/`에는 `YYYY-MM-DD` 날짜 키를 사용합니다. 첫 기록은 최초 상태, 다음 기록부터는 변경 필드만 넣습니다. 잘못된 날짜 키는 새 기록 추가만 하지 말고 삭제·통합하고, 능력·효과·설명과 `<br></br>` 표기를 확인합니다.
- `metadata/`, `tools/` 및 CI에는 검증되지 않은 최초 스펙을 확정하지 않기 위해 필요한 원본 근거와 재현용 코드만 보존합니다. 근거 삭제 전에 빌드·검증의 참조를 전부 제거해야 합니다. 불필요한 신규 호환/스키마 래퍼는 추가하지 않습니다.
